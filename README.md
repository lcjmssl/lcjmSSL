### 主要能力

- **多渠道 CA**：统一对接 Let's Encrypt、Google Trust Services、ZeroSSL，避免单一 CA 出问题时业务停摆。
- **多域名 / 泛域名 / IP 证书**：单张证书最多可包含 100 个域名，内网服务、边缘网关也能用 IP 直接签发。
- **三种自动验证**：DNS 代理（一次 CNAME，长期免维护）、DNS 接口（阿里云、腾讯云、ClouDNS、1Panel 等凭证）、HTTP 代理，任选其一即可自动续期。
- **自动部署**：证书签发后直接推送到服务器、宝塔 / 1Panel 面板与 CDN，省去下载再上传。
- **开放 API**：`Bearer token:user` 鉴权，统一的 GET 接口完成申请、验证、下载、部署，可嵌入 CI/CD、初始化脚本或自建运维平台。
